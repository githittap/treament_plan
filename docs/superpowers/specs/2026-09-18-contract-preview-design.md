# 근로계약서 작성 미리보기

## 범위

- 운영 `hr.html`, Supabase 템플릿·계약 데이터는 변경하지 않는다.
- 별도 HTML 한 파일에서 입력 화면과 계약서 결과를 즉시 확인한다.

## 입력

- 직원 선택, 주민등록번호, 역할(부서), 계약 시작일·종료일, 세전 월급, 세후 예상 실수령액을 둔다.
- 직원 성명은 직원 선택값을 사용하므로 별도 입력하지 않는다.
- 역할은 통역사·진료실·리셉션·상담실장·마케터·부원장·기공소이며, 선택 즉시 수행업무를 자동 입력한다.
- 마케터 업무는 기획, 광고심의, 디자인, 매체별 최적화 설정·광고 집행, 내부 사이니지 변경, 카피라이팅, 오프라인·대외 계약체결 및 치과 업무 보조 전반으로 한다.
- 월 급여(세전)는 계약 기준의 필수값이다. 세후 예상 실수령액은 선택 입력이며 참고값으로만 표시한다.

## 근무시간

- 시간대 행마다 월~일 복수 선택, 주간·야간·별도 구분, 시업·종업·휴게·비고를 입력한다.
- 행을 추가·삭제할 수 있고 계약서에는 표로 출력한다.
- 공휴일 근무는 항상 포함으로 고정 표기한다.

## 상세 조건

- 접힌 기본 상태로 서명 만료일, 근무장소, 수행업무, 포괄구성, 주휴일을 모은다.
- 기본값은 기존 표준서식의 값으로 둔다.
- 계약 종료일을 입력하면 기간의 정함 없음은 자동 해제하고 비활성화한다. 종료일이 비어 있을 때만 선택할 수 있다.

## 계약서 문구

- 퇴직 시 10만원 공제, 퇴직금품의 다음 급여일 지급, 3주 전 퇴사 관련 문구와 해지 조항은 현재 표준서식 문구를 유지한다.

## 검증

- 근무시간 행은 최소 한 요일과 시업·종업시간이 있어야 미리보기에 반영한다.
- 세전 월급은 필수, 세후 예상액은 선택값으로 표시한다.
- 미리보기는 입력값과 역할별 수행업무가 즉시 계약서에 반영되는지 확인한다.
