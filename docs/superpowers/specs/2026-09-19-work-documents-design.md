# 업무자료 탭 설계

## 목표

직원 허브에 독립적인 `📚 업무자료` 탭 하나를 추가하고, 승인된 공개 Notion 링크만 검색 가능한 카드 목록으로 제공한다. Notion iframe은 사용하지 않고 새 창 링크만 사용한다.

## 범위

- 모든 역할(staff, manager, chief, owner)에 탭을 노출한다.
- 초기 자료는 업무 매뉴얼, 필요물품 요청·구매현황 두 건만 등록한다.
- 제목·설명·종류·아이콘·안전한 외부 링크를 표시한다.
- 검색어는 제목·설명·종류에 적용한다.
- 개인·민감 Notion 페이지 탐색, CRUD, iframe, 업무자료 하위 탭은 구현하지 않는다.

## 안전·UI 계약

- 링크는 `target="_blank" rel="noopener"`를 사용한다.
- 기존 직원 허브의 다크 테마·반응형 카드 스타일을 따른다.
- 검색 결과 0건과 기본 목록을 구분한다.
