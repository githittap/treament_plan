# 업무자료 탭 구현계획

1. 설계서와 현재 git 상태를 확인한다.
2. `tests/work-documents.test.js`에 검색·역할·링크 안전속성·렌더 계약을 먼저 작성하고 RED를 확인한다.
3. `hr.html`에 `workdocs` 탭, 고정된 공개 링크 목록, 검색 필터, 카드 렌더를 최소 구현한다.
4. 전체 테스트·inline script 구문·diff를 검증한다.
5. 한국어 커밋을 만들고 push는 환경 정책이 허용할 때만 시도한다.
