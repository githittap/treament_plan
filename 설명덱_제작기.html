설명덱 제작기 사용법

코딩 없이, 왼쪽에서 슬라이드를 추가하고 가운데서 내용을 채우면 오른쪽에 발표가 실시간으로 그려집니다. 다 만들면 ‘발표 파일 만들기’로 더블클릭용 파일을 뽑으세요. 슬라이드는 표지·요약·도표·표·비교·체크리스트·사진, 7가지예요.

3단계

  • 추가 — 왼쪽 ‘＋ 슬라이드 추가’에서 종류 선택 (표지·요약·도표·표·비교·체크리스트·사진)
  • 작성 — 가운데 칸을 타이핑. ‘등장 순서’ 숫자 = 클릭 몇 번째에 나올지 (0 = 열자마자)
  • 내보내기 — ‘발표 파일 만들기’ → 인터넷 없이 더블클릭으로 열리는 발표물 완성

사진 슬라이드

  • 사진 넣기 — 사진을 올리거나 Ctrl+V로 붙여넣어요. 빈 사진 장이면 그 장에, 아니면 뒤에 새 장이 생겨요
  • 화살표 (Q) — 사진을 두 번 눌러요(시작점 → 끝점)
  • 글 (T) — 사진을 누른 자리에 글. Enter로 확정, Shift+Enter는 줄바꿈. 글 한 상자를 넣고 나면 자동으로 선택(A)으로 돌아가요
  • 원 (O) — 원의 가운데를 누른 채 바깥으로 끌어요. 선택(A)에서 테두리를 끌면 옮기고, 색·효과는 줄 아래에서 바꿔요
  • 선택 (A) — 화살표·글을 끌어 옮겨요
  • 꺾기 (R) — 고른 화살표에 꺾임점이 더해져요. 점을 끌어 모양을 만들고, R을 또 누르면 한 번 더 꺾여요. Shift+R은 다시 펴요. 꺾임점을 두 번 누르면 빠져요
  • 순서 칸 — 비우면 바로 보이고, 숫자 = 클릭 몇 번째에 나올지
  • 꾸미기 — 줄 아래에서 글자색·배경색·크기·효과를 바꿔요(‘기본으로’로 되돌림). 글이 서로 겹치면 자동으로 비켜 앉아요
  • 확대·이동 — Ctrl+휠 또는 ＋/－로 확대해요. 이동은 확대 중 빈 곳 끌기(A) 또는 Space를 누른 채 끌기(끌지 않고 떼면 다음 장)
  • 편집 칸 넓히기 — 미리보기의 ‘접기 ▸’를 누르면 편집 칸이 넓어져요
  • 장 이동 — 왼쪽 위 ‘장 이동’ 칸에 번호를 치고 Enter

저장 vs 내보내기

  • 직원허브에서 연 편집 — 고칠 때마다 자동 저장돼요(마지막으로 고친 뒤 2.5초). 위쪽에 ‘저장 안 됨’ → ‘저장됨’이 보여요
  • 저장 — 허브 밖에서는 이 브라우저에 임시 보관(작업 이어하기용)
  • 불러오기 — ‘발표 파일 만들기’로 만든 .html·.json 파일만 열려요. 허브에서는 내용이 통째로 바뀌고 곧 자동 저장돼요
  • 발표 파일 만들기 — 사진·효과가 담긴 완성본 HTML 한 파일을 내려받음(사진이 많으면 파일이 커요)
